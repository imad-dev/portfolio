# Imad Hadda — Portfolio

Personal portfolio site for Imad Hadda.
Built with HTML, CSS, and vanilla JS.
Deployed on Vercel.

## Stack

- HTML5 / CSS3 / React + Vite
- Fonts: Syne + Inter + JetBrains Mono (Google Fonts)
- Animation: Framer Motion
- Styling: Tailwind CSS v4
- Deployment: Vercel

## Local Development

```bash
# Install dependencies
npm install

# Start dev server
npm run dev
```

## Production Build

```bash
npm run build
```

## Deployment

Push to `main` branch — Vercel auto-deploys.

Live URL: [https://imad-hadda.vercel.app](https://imad-hadda.vercel.app)
